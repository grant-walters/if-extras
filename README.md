# IF: Extras

A client-side Fabric mod that adds quality-of-life features for the ImagineFun Minecraft server.

## Keybinds

`\` : open the HUD editor.

## Features

- **Ride progress**: shows the ride you're on, a timer and progress bar, and how many times and how long you've ridden it.
- **Coins & Magic Keys**: your current balances, always on screen.
- **Players & multiplier**: the server's player count and the current coin multiplier.
- **Party**: your party's leader and members, kept up to date as people join and leave.
- **Clock**: your local time.

The vanilla scoreboard is hidden on ImagineFun, since the HUD shows the same information.

## Customizing the HUD

Press `\` (rebindable in Controls) to open the HUD editor:

- **Click & drag** to move an element
- **Scroll** over an element to resize it
- **Double-click** an element to turn it on or off
- **Reset GUI** puts every element back in its default position

## Requirements

- Minecraft 26.2
- Fabric Loader 0.19.5+
- [Fabric API](https://modrinth.com/mod/fabric-api)
- [ImagineFunUtils](https://modrinth.com/mod/imaginefunutils) 0.0.9+
